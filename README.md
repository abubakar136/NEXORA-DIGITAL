
# NEXORA DIGITAL

## Project Overview
NEXORA DIGITAL is a simple, modern website created as part of the Devixo Solutions internship. The website introduces digital services through a clean and user-friendly interface.

## Internship Details
- **Organization:** Devixo Solutions
- **Project Name:** NEXORA DIGITAL
- **Internship Domain:** Web Development
- **Task Number:** Task 2

## Objective
The objective of this project is to develop a simple website using HTML, CSS, and JavaScript to practice website structure, styling, and interactivity.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Navigation bar
- Homepage hero section
- About section
- Services section
- Contact section
- Dark and light theme toggle
- Responsive design

## Project Structure

```text
NEXORA-DIGITAL/
├── index.html

├── images/
├── screenshots/
└── README.md
```

## How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
